One tool call, checked at every step
What happens between a WSO2 agent deciding to use a tool and the tool running
Amazon Bedrock AgentCoreWSO2 Integration Platform
1
WSO2 agent

Decides to use a tool

Sends the call to the Gateway with its short-lived token. It can only pick from tools it was shown.

2
Identity

Caller verified

The token is checked on every call. An unknown or expired caller stops here.

3
Policy

Decision made

Cedar rules are evaluated against the call and its arguments, with Bedrock Guardrails screening the content.

4
WSO2 tool service

Tool runs

The Gateway calls the service with its own AWS role. For model calls, the key comes from the vault.

5
Observability

On the record

The call, its result and the policy decision land in the conversation's trace.

6
Evaluations

Scored later

The finished conversation is judged from the same trace, with written reasoning.

Denied
The call never reaches the tool. The agent gets a refusal, and the decision is recorded in the trace like any other.
